# ALLURE Frontend

## Overview

ALLURE is a modern fashion e-commerce web application that provides customers with a seamless online shopping experience. This frontend connects to the ALLURE backend API and allows users to browse products, manage their shopping cart, complete purchases, and manage their accounts through a clean and responsive interface.

---

## Features

* User Authentication (Login & Logout)
* Customer Registration
* Product Catalog
* Product Search and Filtering
* Product Details
* Shopping Cart
* Checkout Experience
* Shipping Method Selection
* Order Summary
* Responsive User Interface
* Customer Profile Management

## Installation

1. Clone the repository.

2. Open the project in IntelliJ IDEA or Visual Studio Code.

3. Ensure the ALLURE Backend API is running.

4. Open `index.html` or start your preferred local web server.
